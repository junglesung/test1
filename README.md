# 空中堡壘

靜態網頁飛行射擊遊戲。點擊即可在手機、平板、電腦上直接遊玩，無需建置。

## 遊玩方式

1. 打開 `index.html`
2. 點擊「開始任務」或遊戲畫面
3. 移動指標／觸控引導飛機方向
4. 使用底部武器：
   - **雷射**：無限，前方準線直線射擊
   - **巨型炸彈**：無限，清除所有子彈並向四周發射雷射
   - **防護衣**：無限可切換，但被擊中時不會防護

## 規則

- 每個城堡約直徑 5 cm（螢幕比例），內有可旋轉射擊的坦克（射速 2.5 倍）與一排旋轉砲（發射雷射）
- 敵機會從四面八方飛來
- 被擊中一次即失敗；摧毀全部城堡即勝利
- 玩家飛行速度約為 5 秒可抵達一座城堡的距離

## 操作

| 操作 | 說明 |
|------|------|
| 指標／觸控 | 引導飛行方向；按住可持續射雷射 |
| `1` | 切換雷射 |
| `2` / 巨型炸彈按鈕 | 發射巨型炸彈 |
| `3` / 防護衣按鈕 | 切換防護衣 |
| `空白鍵` | 依目前武器開火 |
